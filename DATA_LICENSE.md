# Public data attribution

Fanaee-T, H. (2013). **Bike Sharing** [Dataset]. UCI Machine Learning Repository.
DOI: https://doi.org/10.24432/C5W894

Source: https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset

The source dataset is licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
The `artifacts/demo_features.csv` and `reports/holdout_predictions.csv` files
contain transformed observations from that source and retain this attribution.
Transformations include clock-hour alignment, lag/rolling features, chronological
selection, and model predictions. Training weights and reports were created by
this project; they are not artifacts supplied by UCI.

This is public 2011–2012 aggregate bike-rental data, not customer records from a
current employer or a live bike-sharing service. The application uses historical
data to demonstrate a forecasting workflow.
